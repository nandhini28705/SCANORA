SCANORA – Image Quality Analyzer

SCANORA is a web-based application that analyzes image quality and improves images using image processing techniques.

Features

- Upload images (JPG, JPEG, PNG)
- Brightness analysis
- Sharpness analysis
- Contrast analysis
- Image quality score
- OCR text detection
- Image enhancement
- PDF report generation
- Analysis history

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- OpenCV / Pillow
- Tesseract OCR

Project Goal

To analyze image quality and enhance images for better readability and clarity.
